## 📌 Sobre o Projeto
Este sistema foi desenvolvido como solução para o desafio de otimização do agendamento de visitas às unidades da **Wilson Sons**. O foco principal foi centralizar o processo de credenciamento, garantindo que 100% dos visitantes passem por uma integração de segurança obrigatória antes do acesso aos terminais e estaleiros.

---

## 🛠️ Tecnologias Utilizadas
*   **Front-end:** [Lovable](https://lovable.dev/) (Interface moderna com tendências UI 2026).
*   **Back-end & Banco de Dados:** Google Sheets.
*   **Automação:** Google Apps Script (Notificações automáticas via E-mail).
*   **Coleta de Dados:** Google Forms (Integrado via Iframe).
*   **Engenharia de Prompt:** IA utilizada para estruturação de código, design e roteiro de segurança.

---

## ✨ Funcionalidades Principais
1.  **Landing Page de Alta Autoridade:** Interface responsiva seguindo o branding oficial (#003358 e #00BEDD).
2.  **Integração de Segurança:** Visualização obrigatória de vídeo institucional integrada à jornada do usuário.
3.  **Split Layout Informativo:** Cards visuais detalhando vestimentas proibidas e EPIs obrigatórios (Capacete, Botas e Colete).
4.  **Sticky Scroll Scheduling:** Formulário de agendamento em layout 40/60, mantendo as instruções fixas na tela durante o preenchimento.
5.  **Quiz de Validação:** Filtro de segurança que garante o conhecimento do visitante sobre os riscos portuários.
6.  **Notificação Automática:** Apps Script configurado para disparar e-mails de confirmação com resumo do agendamento e reforço das normas de segurança.

---

## 🎨 Identidade Visual (UI/UX)
O projeto aplica tendências modernas de 2026:
*   **Glassmorphism:** Header com desfoque de fundo e transparência.
*   **Bento Grid:** Organização de informações de segurança em blocos limpos e visuais.
*   **Soft Depth:** Uso de sombras suaves em vez de bordas sólidas, criando profundidade.
*   **Engineering Grid:** Fundo pontilhado sutil reforçando o DNA industrial e de logística.
